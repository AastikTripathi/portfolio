🔒 Local-First JSON Database Architectures and Offline Backups

June 14, 2026 · 3 minute read · Local Storage & Database

Managing application state offline requires a robust database system that handles quick reads, updates, and structures serialization correctly. For Sanctuary, we designed a local JSON storage model that writes directly to the device's sandbox document directory.

File-Based Serialization

Instead of introducing heavy SQLite configuration binaries, all models (Thoughts, Habit Logs, Physical Logs, and Habit Definitions) implement standard JSON serialization in Dart. On write transactions, the entire state is encoded and flushed to a single local file asynchronously: 

Future<void> _saveAllData() async {
  final file = await _getSaveFile();
  final data = {
    'thoughts': _thoughts.map((t) => t.toJson()).toList(),
    'physical_logs': _physicalLogs.map((p) => p.toJson()).toList(),
    'habit_definitions': _habitDefinitions.map((h) => h.toJson()).toList(),
    'habit_logs': _habitLogs.map((hl) => hl.toJson()).toList(),
  };
  await file.writeAsString(jsonEncode(data));
}

Export & Import Safeguards

Since files are saved in the app's local sandbox, deleting the app wipes out the data. To prevent data loss, we built local backup and restore utilities. The export feature extracts the raw JSON string and opens the native file sharing menu, allowing users to save the backup to their filesystem. The import feature reads the file back, parses/validates the JSON keys, and re-initializes the app database.
