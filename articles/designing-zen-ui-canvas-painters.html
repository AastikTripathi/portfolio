🎨 Designing Zen UI: Canvas Painters and Plant Physics in Flutter

May 15, 2026 · 4 minute read · UI & Canvas Graphics

In health and habit logging applications, the UI is often clinical, rigid, and filled with warning progress bars. When building Sanctuary, we wanted a screen that felt peaceful and alive. We decided to map the user's routine consistency directly to a virtual garden containing growing plants and floating fireflies.

This essay outlines how we used Flutter's CustomPainter class to render organic procedural growth models that react dynamically to user behavior.

The CustomPainter Architecture

Flutter's CustomPainter provides access to a low-level Canvas API. To draw organic curves instead of simple geometric bars, we construct quadratic bezier paths representing plant stems: 

// Drawing a plant stem with Bezier curves
final path = Path();
path.moveTo(bottomX, bottomY);
path.quadraticBezierTo(
  controlPointX,
  controlPointY,
  tipX,
  tipY,
);
canvas.drawPath(path, stemPaint);

Mapping Growth Dynamics to Consistency

We query the database for the user's habit completions over the past seven days. This completion percentage is mapped to a growth index (0.0 to 1.0) that determines:

  • The length and angle of the main stem.
  • The number of procedural branches that grow out.
  • The scale and color of the leaves.

This organic representation rewards users for their routine consistency with a blooming virtual companion, rather than using stressful streaks or notification alerts.

Ambient Firefly Physics

To make the garden feel alive even when the user is idle, we implemented an ambient firefly simulator. Each firefly is modeled as an independent particle with position, velocity, and a sine-wave based glowing opacity.

We use a standard animation controller to trigger tick updates, updating the positions in memory and requesting a canvas repaint at 60 FPS, ensuring that Sanctuary remains a calm, immersive digital sanctuary.
