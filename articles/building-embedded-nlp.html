🧠 Embedding Small Language Categorizers in Mobile Application Sandboxes

April 12, 2026 · 3 minute read · Embedded NLP & Search

Health journaling apps often benefit from categorizing thoughts automatically. However, standard NLP models require heavy server architectures or large on-device neural network runtimes. For Sanctuary, we implemented a lightweight, fast tf-idf/cosine similarity matching system in raw Dart.

Tokenization & Stopwords Filtering

The input text is tokenized into clean lowercase words, filtering out common English stopwords (like "the", "is", "at") to isolate the core semantic tokens.

Semantic Tag Recommendation

We build term frequency vectors for current journal entries and historical entries. The recommendation engine computes cosine similarities on-the-fly, suggesting relevant past tags based on entry themes. This offers cohesive, context-aware metadata recommendations directly inside the Flutter sandbox in under 1 millisecond.
