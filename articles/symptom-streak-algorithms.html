📊 Mathematical Streak Algorithms: Days Elapsed, Intervals, and Gaps

May 20, 2026 · 3 minute read · Analytics & Algorithms

Unlike habit streaks which count consecutive days of action, symptom tracking requires counting consecutive days of non-action (symptom-free days). Computing these intervals accurately requires scanning chronological time series lists and isolating incident gaps.

Chronological Interval Calculation

First, we filter and map all physical logs containing active symptoms (e.g. seizures or custom event spikes) to a sorted list of unique DateTime stamps.

To find the average time between events, we iterate over the sorted timestamps and calculate the gap in days between consecutive flare days: 

double sumGaps = 0;
for (int i = 1; i < flareDates.length; i++) {
  sumGaps += flareDates[i].difference(flareDates[i - 1]).inDays;
}
final avgGap = sumGaps / (flareDates.length - 1);

Longest Streak Logic

The longest streak represents the maximum symptom-free interval. We compute this by checking the gaps between all consecutive events, and comparing them with the gap between the latest event and today: 

int longestStreak = 0;
for (int i = 1; i < flareDates.length; i++) {
  final gap = flareDates[i].difference(flareDates[i - 1]).inDays - 1;
  if (gap > longestStreak) longestStreak = gap;
}
final currentGap = today.difference(flareDates.last).inDays - 1;
if (currentGap > longestStreak) longestStreak = currentGap;

This isolates the metrics efficiently and supports user motivation by highlighting their longest symptom-free progress.
