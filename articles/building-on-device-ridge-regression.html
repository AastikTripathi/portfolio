🌱 Sanctuary: The Math Behind On-Device Regularization

July 8, 2026 · 6 minute read · Mobile & Local ML

In a world dominated by cloud APIs and remote LLM inferences, building advanced user analytics running completely offline inside a mobile sandbox is both a challenge and a statement. For Sanctuary, a privacy-first symptom and routine journal, sending user inputs to cloud databases was out of the question.

To find correlation triggers between sleep, cycle phases, active custom symptoms (like pain level or seizure spikes), and mood metrics, we needed a robust modeling algorithm. This essay breaks down how we built a synchronous L2 Regularized Ridge Regression engine directly inside a Flutter application.

Why Ridge Regression?

Ordinary Least Squares (OLS) regression breaks down when variables are highly collinear (e.g., tracking both caffeine intake and sleep quality on the same day). On small datasets (such as a single user's 30-day log history), OLS easily overfits, resulting in wild, physically meaningless coefficient swings.

L2 Regularization (Ridge Regression) solves this by adding a penalty parameter (lambda/alpha) to the cost function: 

Cost = ||y - Xw||² + λ||w||²

This forces the coefficients (weights) to shrink toward zero, suppressing collinearity noise and ensuring that predictions stay stable even with limited daily logs.

Implementing Matrix Math from Scratch in Dart

Flutter does not bundle native linear algebra solvers. To solve the normal equation for Ridge Regression: 

w = (XᵀX + λI)⁻¹ Xᵀy

We had to implement a custom matrix math library in Dart, handling transpose, multiplication, and matrix inversion using Gaussian elimination. 

// Matrix Inversion via Gaussian Elimination
List<List<double>>? invert(List<List<double>> A) {
  int n = A.length;
  // Initialize identity matrix I
  List<List<double>> I = List.generate(n, (i) => 
    List.generate(n, (j) => i == j ? 1.0 : 0.0)
  );

  // Perform forward elimination & back substitution
  for (int i = 0; i < n; i++) {
    double pivot = A[i][i];
    if (pivot.abs() < 1e-9) return null; // Singular matrix

    for (int j = 0; j < n; j++) {
      A[i][j] /= pivot;
      I[i][j] /= pivot;
    }

    for (int k = 0; k < n; k++) {
      if (k == i) continue;
      double factor = A[k][i];
      for (int j = 0; j < n; j++) {
        A[k][j] -= factor * A[i][j];
        I[k][j] -= factor * I[i][j];
      }
    }
  }
  return I;
}

Isolating Anomalies (The Stress Shield)

One of the major problems with health journaling is that mood is heavily affected by things outside of daily routines—such as a sudden family emergency or a bad day at work.

To prevent these massive outliers from polluting regular habit correlations, we introduced a toggle card: Unusual / Highly Stressful Note. When toggled by the user, the engine maps this as a separate binary indicator (an externalShockShield column in the matrix). This isolates the stress variance, keeping the other routine coefficients mathematically clean.

Results

By embedding this engine directly in Sanctuary, users can see how each routine (like gardening, exercise, or study) affects their baseline headspace. Calculations finish in under 2 milliseconds inside the sandbox—ensuring user privacy remains absolute while delivering personalized analytics.
